Confirmed source defects/gaps include the Flutter export async lifecycle error, best-effort Node audit logging, unshared rate limiting, missing provider-backed OAuth registration, incomplete MFA-recovery completion, and incomplete cross-product data lifecycle. The Stripe FK discrepancy is a **conditional deployment risk**, not a demonstrated production failure. Existing file review is not a claim of comprehensive line-by-line or full 135-item acceptance.
