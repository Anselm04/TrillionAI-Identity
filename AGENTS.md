# Mandatory reference-first Identity engineering

Before every substantive change inspect exact source files in commercially validated open-source reference projects. Require documented actual paying customers or revenue, not funding, stars or pricing alone. Revenue does not certify security. Record upstream/destination revision, file paths, license, applicable pattern, differences and executed tests. No incompatible source copying. Preserve one underlying authentication authority (Supabase Auth for the canonical implementation), independent tenant boundaries, portable customer deployments and existing spending restrictions. Do not merge, deploy, apply shared database migrations or change other products without authorization. Never report unexecuted tests as passed.
